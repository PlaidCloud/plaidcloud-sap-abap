# Changelog

All notable changes to this package are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [1.0.0]

### Added

- Table catalog and keyset table reader with predicate safety.
- SQ01 query catalog, run, and selection-screen support.
- Transaction/report catalog, run, selection-screen, and variant support.
- Staged streaming for large result sets.
- Async execution for long-running extracts, with status and cancel.
- Capabilities/healthcheck function module reporting package version and environment readiness.
- Authorization preflight check.
